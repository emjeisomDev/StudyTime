# StudyTime API

API REST para gestão de tempo de estudo semanal, desenvolvida com
.NET 10 e PostgreSQL 17, seguindo os princípios de Clean Architecture.

## Tecnologias

- .NET SDK 10.0.401
- C# 14
- PostgreSQL 17
- Docker e Docker Compose

## Pré-requisitos

- .NET SDK 10.0.401
- Docker Engine
- Docker Compose

O SDK é fixado pelo arquivo `global.json`. Para conferir a versão ativa:

```bash
dotnet --version
